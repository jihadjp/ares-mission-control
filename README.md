# 🚀 Ares Mission Control

**Ares Mission Control** is a strategic, web-based resource management simulator built by **Team Astronex** for the **NASA Space Apps Challenge 2026**.

Players step into the role of a Mars Outpost Commander, tasked with keeping their crew alive in an extreme extraterrestrial environment. By balancing critical systems—Power, Oxygen, Water, Food, and Radiation Shielding—and making tough engineering trade-offs during random events like Solar Flares and Dust Storms, players experience firsthand the complexities of space mission design.

### ✨ Key Features
- **Dynamic Mission Durations:** Choose a 30-Sol sprint, a standard 50-Sol mission, or an epic 100-Sol survival challenge.
- **Interactive Resource Engine:** Real-time tracking of vitals where every decision directly impacts crew health and morale.
- **Crisis Management:** Rule-based event system simulating realistic Martian hazards.
- **Modern Tech Stack:** Built with React, TypeScript (.tsx), and Tailwind CSS for a highly responsive, glassmorphic sci-fi HUD experience.
